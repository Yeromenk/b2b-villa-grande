# Обновление товаров

Все команды запускаются из `b2b-villa-grande/back-end`. После импорта нажмите кнопку с круговой стрелкой «Оновити каталог» возле поиска на сайте или обновите страницу. При возвращении фокуса в окно сайта каталог тоже обновляется.

## Ceramamarket — без входа в аккаунт

Все четыре раздела:

```powershell
npm.cmd run import:ceramamarket
```

Один раздел:

```powershell
npm.cmd run import:ceramamarket -- --section tiles
npm.cmd run import:ceramamarket -- --section plumbing
npm.cmd run import:ceramamarket -- --section flooring
npm.cmd run import:ceramamarket -- --section panels
```

`tiles` — плитка, `plumbing` — сантехника, `flooring` — покрытия для пола, `panels` — панели. Поддерживаются `all` и список через запятую. Справка: `npm.cmd run import:ceramamarket -- --help`.

Импорт обходит все страницы каждого указанного раздела по 150 карточек. Учитывает robots.txt и делает паузы между запросами. Берёт текущую публичную цену (включая скидку) в UAH, единицу продажи, название, бренд, наличие, изображение и основную подкатегорию из пути товара и меню сайта. Один товар может участвовать в нескольких тематических подборках сайта поставщика; здесь сохраняется его основная подкатегория.

Артикул и детальные характеристики не доступны в списочных карточках: артикул остаётся пустым, идентичность товара определяется внутренним ID Ceramamarket. Цвет для фильтрации берётся из явных слов в названии на фронтенде. Товары без цены/с нулевой ценой пропускаются. Непонятная цена, чужая ссылка или ошибка пагинации останавливают обновление раздела, сохраняя предыдущие данные.

## Laterem — вход через отдельное окно Chrome

```powershell
.\open-laterem.ps1
```

Войдите в аккаунт в открывшемся окне, откройте каталог, затем запустите нужную команду:

```powershell
npm.cmd run import:laterem -- --section plumbing
npm.cmd run import:laterem -- --section tiles
npm.cmd run import:laterem -- --section stone
npm.cmd run import:laterem -- --section spa
npm.cmd run import:laterem -- --section engineering
```

Для всех пяти разделов: `npm.cmd run import:laterem -- --section all`. Без параметров обновляется только сантехника. Несколько разделов: `--section tiles,stone,spa,engineering`. Раздел, открытый в Chrome, не меняет выбор в команде.

Чтобы быстро дополнить существующий каталог реальными закупочными ценами без полного обновления товаров:

```powershell
npm.cmd run import:laterem:purchase-prices
```

Команда по умолчанию полностью обрабатывает все пять разделов и обновляет только найденные существующие товары. Для одного раздела можно передать `-- --section plumbing`, `tiles`, `stone`, `spa` или `engineering`.

Используется РРЦ в EUR с пересчётом по курсу из шапки Laterem. Закупочная цена `price_opt` сохраняется отдельно и пересчитывается по тому же курсу; для заполнения закупочных цен в старом каталоге повторите импорт. В интерфейсе курс EUR показывается с датой последнего успешного импорта. Нулевые цены пропускаются. Единицы продажи списочный API Laterem не передаёт, поэтому они не угадываются. Пароль и токен не сохраняются в проекте.

## Где хранятся данные

`data/catalog.sqlite` — локальная база SQLite (или путь `DATABASE_PATH`). Изображения загружаются по ссылкам поставщиков. В таблице `import_runs` находятся отчёты о загрузке.

Обновление каждого раздела применяется одной транзакцией только после завершения обхода. Оно обновляет/удаляет записи исключительно этого поставщика и раздела. Остальные разделы и поставщики остаются на месте. ID существующих товаров сохраняются; предложения разных поставщиков не объединяются. При ошибке в одном разделе остальные выбранные разделы продолжают импортироваться, итоговый код команды — 1.

Синхронизация запускается вручную. Браузер Laterem нужен только для его импорта; Ceramamarket и просмотр уже загруженных товаров от него не зависят.
