# Villa Grande: каталог и импорт товаров

Актуальные команды обновления Laterem и Ceramamarket по разделам: [IMPORT.md](./IMPORT.md).

Первый этап бэкенда: Node.js 24.13+, SQLite, API каталога и CLI-импорт публичных страниц товаров. Каталог, счётчики разделов и спецификация используют товары из API. Заказы сохраняются в SQLite через API, контактные данные профиля — в локальном хранилище браузера.

## Запуск

В терминале из `back-end`:

```powershell
npm.cmd install
npm.cmd run dev
```

Во втором терминале из `front-end`:

```powershell
npm.cmd install
npm.cmd run dev
```

Vite перенаправляет `/api` на `127.0.0.1:3001`. Для production нужен reverse proxy с таким же маршрутом. API по умолчанию слушает только loopback; настройки: `HOST`, `PORT`, `DATABASE_PATH`. База автоматически создаётся в `back-end/data/catalog.sqlite`, если запускать команды из `back-end`. При первом запуске каталог пуст: демонстрационные товары автоматически не подмешиваются.

## Импорт

### Laterem: импорт авторизованного каталога

Из `back-end` откройте отдельный Chrome, войдите в Laterem и откройте каталог:

```powershell
.\open-laterem.ps1
npm.cmd run import:laterem
```

Импорт использует текущую сессию этого браузера через локальный порт 9222. Пароль и токен не записываются в проект, базу или логи. Профиль Chrome находится в `%TEMP%/laterem-browser-session`; после окончания работы окно можно закрыть. Для следующего обновления снова откройте его; если сессия истекла, войдите заново.

Загружается весь каталог сантехники (`category=0`), по 100 товаров с паузой между страницами. По умолчанию используется **РРЦ** (`price_1`) в EUR. Курс EUR/UAH читается из шапки Laterem при импорте; в базе хранится цена UAH, исходная цена EUR и использованный курс. API передаёт этот курс фронтенду. В интерфейсе показывается только EUR, источник и дата последнего успешного импорта; это курс снимка каталога, а не онлайн-курс.

Для другой цены можно задать `$env:LATEREM_PRICE_FIELD = 'onlinePrice'` или `'price_opt'` (закупочная цена), затем повторить импорт. Выбранная цена будет доступна всем пользователям вашего API. Закупочная цена `price_opt` сохраняется отдельно в `purchasePriceEur` и `purchasePrice` (UAH). Пустая или нулевая закупочная цена отображается как отсутствующая. Для ранее импортированных товаров нужен повторный импорт; сохранённые заказы остаются снимками цен на момент создания.

Товары с нулевой ценой пропускаются и учитываются в `skippedZeroPrice`. Наличие берётся из `stock`; резерв и товары в пути не считаются доступным остатком. Цвет, монтаж и ценовой сегмент не угадываются по названию. Изображения загружаются напрямую с Laterem.

Обновление применяется одной транзакцией только после проверки всех страниц. ID существующих товаров сохраняются; исчезнувшие из полного каталога и товары с нулевой ценой удаляются только у Laterem. Остальные поставщики не затрагиваются. Если импорт прервался, существующий каталог сохраняется. Результат записывается в `import_runs`.

После успешного импорта обновите страницу вашего сайта. Это локальная загрузка снимка каталога, а не постоянная синхронизация: для новых цен/остатков повторите команду. Для работы сайта после импорта браузер Laterem не нужен. Автоматическое расписание и серверная авторизация поставщика пока не настроены.

### Публичные страницы JSON-LD

1. Скопируйте `sources.example.json` в `sources.local.json`.
2. Замените демонстрационный домен настоящим поставщиком и укажите прямые ссылки на страницы товаров в `urls`. `origin` — точный HTTPS origin без завершающего слеша. Каждый источник имеет постоянный уникальный `id`.
3. Запустите из `back-end`:

```powershell
npm.cmd run import -- sources.local.json
```

После импорта обновите страницу каталога. Повторяйте команду для обновления цен; автоматического расписания пока нет. Сервер и импорт могут работать одновременно. Записи обновляются по паре источник + SKU/MPN, при отсутствии артикула — по URL. ID товара сохраняется, одинаковые артикулы разных поставщиков остаются отдельными предложениями. Отсутствующие при следующем импорте записи не удаляются; дата последнего успешного импорта хранится в `importedAt`.

Вывод команды содержит количество обработанных товаров и ошибки по источникам/страницам. Отчёты также записываются в таблицу `import_runs`; при любой ошибке код завершения равен 1, успешно обработанные страницы сохраняются.

Поддерживаются JSON-LD `Product`, массивы и `@graph`, вложенный `Offer`, название, бренд, SKU/MPN, цена, наличие, изображение. Цена должна быть явно указана в UAH: иностранные валюты, диапазоны AggregateOffer и отсутствующие/неоднозначные цены отклоняются. Категорию можно задать в конфигурации, иначе используется категория страницы. `department` обязателен (`Сантехніка` или `Двері`); `segment` и `installation` можно указать явно. Неизвестные наличие и сегмент не подменяются выдуманными значениями.

Это адаптер прямых страниц со статическим JSON-LD, а не универсальный обход всех магазинов. Обход категорий, пагинация, JavaScript-рендеринг и нестандартная HTML-разметка требуют адаптера под конкретный сайт. Внешние изображения отображаются по исходным ссылкам, поэтому поставщик может блокировать их загрузку. Для авторизованного каталога Laterem предусмотрена отдельная команда выше.

Импорт запускается только локальной CLI-командой, публичного API импорта нет. Загрузчик проверяет robots.txt, ограничивает частоту (минимум 1 секунда), размер ответа (3 MB), время запроса (15 секунд), домен и публичные IP-адреса, закрепляет проверенный DNS-адрес при подключении. Перенаправления страниц товаров отклоняются: укажите конечный разрешённый URL. CAPTCHA и авторизация не обходятся.

## API и проверки

- `GET /api/health` → `{ "status": "ok" }`
- `GET /api/products` → `{ "products": [...] }` — весь каталог для существующих клиентских фильтров и пагинации. Для большого каталога следующий этап — серверная фильтрация и пагинация.
- `npm.cmd test` — парсинг, нормализация, повторный импорт, сохранение базы, robots.txt, ограничения URL/IP и интеграция импорта с API. Тесты используют локальные фикстуры, внешние магазины не вызываются.

Использованы [Node SQLite](https://nodejs.org/api/sqlite.html), [Cheerio](https://cheerio.js.org/docs/basics/loading/) и формат [Schema.org Offer](https://schema.org/Offer).

## PDF предложения

В деталях сохранённого заказа кнопка «Завантажити PDF» создаёт документ A4 с именем заказчика, фотографиями, названиями, количеством, ценами со скидкой и итогом. Валюта соответствует выбранной в интерфейсе (UAH/EUR); закупочные цены не включаются. Длинные таблицы продолжаются на следующих страницах. Перед скачиванием сохраните изменения заказа.

Фотографии загружаются через `GET /api/orders/:id/items/:lineId/image` по адресам из сохранённого заказа. Поддерживаются изображения Laterem и Ceramamarket; произвольные URL от клиента не принимаются. Недоступное фото заменяется подписью, остальные данные сохраняются в PDF. Шрифты Noto Sans включены в фронтенд с лицензией OFL.
