# Запуск Villa Grande

Потрібні Node.js версії 24.13.0 або новішої та npm. Для оновлення даних Laterem також потрібні Google Chrome і обліковий запис Laterem. Наведені команди призначені для PowerShell у Windows.

## Запуск програми

Відкрийте термінал у папці `b2b-villa-grande` та запустіть сервер:

```
cd back-end
```
```
npm.cmd ci
```
```
npm.cmd run dev
```

Відкрийте другий термінал у папці `b2b-villa-grande` та запустіть інтерфейс:

```
cd front-end
```
```
npm.cmd ci
```
```
npm.cmd run dev
```

Відкрийте в браузері адресу, яку виведе другий термінал, зазвичай `http://localhost:5173`. Сервер працює на `http://127.0.0.1:3001`.

Залишайте обидва термінали відкритими. Для зупинки натисніть `Ctrl+C` у кожному. Під час наступних запусків достатньо виконати `npm.cmd run dev` у відповідних папках; повторюйте `npm.cmd ci`, якщо змінилися залежності.

База даних створюється автоматично у `back-end/data/catalog.sqlite`. Якщо каталог порожній, завантажте товари командами нижче.

## Самостійне оновлення даних із двох сайтів

Відкрийте окремий термінал у папці `b2b-villa-grande/back-end`. Якщо залежності сервера ще не встановлені, виконайте `npm.cmd ci`.

Скрипти можна запускати незалежно від програми або під час її роботи. Вони записують дані в ту саму базу, тому запускайте їх саме з папки `back-end`. Якщо використовуєте власний `DATABASE_PATH`, задайте однаковий шлях для сервера та скриптів.

### Laterem

Відкрийте окреме вікно Chrome:

```powershell
.\open-laterem.ps1
```

У цьому вікні увійдіть у свій обліковий запис Laterem та відкрийте каталог. Залиште вікно відкритим і запустіть оновлення всіх п’яти розділів:

```powershell
npm.cmd run import:laterem -- --section all
```
Логін - ``` o.yeromenko@laterem.ua ```
Пароль - ```  Oe4hW2sT59 ```

Оновлення данних може зайняти кілька хвилин. Для латерен було приблизно 7-10 хвилин.

Для оновлення окремого розділу замініть `all` на потрібне значення:

| Значення | Розділ |
| --- | --- |
| `plumbing` | Сантехніка |
| `tiles` | Плитка |
| `stone` | Камінь |
| `spa` | СПА |
| `engineering` | Інженерія |

Наприклад, оновлення плитки та каменю:

```powershell
npm.cmd run import:laterem -- --section tiles,stone
```

Без `--section` команда оновлює лише сантехніку. Розділ, відкритий у Chrome, не визначає вибір скрипта.

Якщо з'являється `Could not identify the Laterem EUR/UAH rate`, перевірте, що в імпортному Chrome відкритий каталог і видно курс. Скрипт очікує появи курсу до 15 секунд. Якщо він усе одно не визначається, задайте курс EUR/UAH, показаний саме на Laterem, вручну:

```powershell
$env:LATEREM_EUR_UAH = Read-Host 'Введіть поточний курс EUR/UAH із Laterem'
npm.cmd run import:laterem -- --section all
Remove-Item Env:LATEREM_EUR_UAH
```

Ця змінна також діє для оновлення закупівельних цін. Видаліть її після імпорту, щоб наступного разу курс визначався автоматично.

Щоб оновити тільки закупівельні ціни вже завантажених товарів усіх розділів, виконайте:

```powershell
npm.cmd run import:laterem:purchase-prices
```

Після завершення вікно Chrome можна закрити. Перед наступним оновленням знову запустіть `open-laterem.ps1` і за потреби повторно увійдіть в обліковий запис.

### Ceramamarket

Для оновлення всіх чотирьох розділів виконайте:

```powershell
npm.cmd run import:ceramamarket
```

Вхід в обліковий запис і відкрите вікно Chrome не потрібні.

Для окремого розділу використовуйте `--section`:

```powershell
npm.cmd run import:ceramamarket -- --section tiles
```

| Значення | Розділ |
| --- | --- |
| `tiles` | Плитка |
| `plumbing` | Сантехніка |
| `flooring` | Покриття для підлоги |
| `panels` | Панелі |

Можна вказати кілька розділів через кому, наприклад `--section tiles,plumbing`, або всі розділи: `--section all`.

Тут десь 4-6 хвилини на оновлення всіх розділів.

### Після оновлення

Дочекайтеся завершення команди та перевірте повідомлення в терміналі. Після успішного імпорту оновіть сторінку програми або натисніть «Оновити каталог» біля пошуку.

Повне оновлення розділу також видаляє з локального каталогу товари цього розділу, які більше не надходять від постачальника. Якщо оновлення розділу завершилося помилкою, попередні дані цього розділу зберігаються; перевірте причину в терміналі та повторіть команду.

Автоматичного розкладу немає: для отримання актуальних цін і залишків запускайте відповідні команди повторно.
